# 掌中的语言学习环境

**jidoujisho** 是视频播放器、阅读辅助、词典和卡片创建工具包，专门面向语言学习者的沉浸式学习场景。

* 点按或拖选字幕和段落，可以立即进行词典查询。
* 可导出到 **AnkiDroid**，并附带当前上下文的图片和音频。
* 可从本地设备、YouTube、Jellyfin 媒体库或直接 URL 观看带字幕视频，或收听带字幕音频。
* 通过内嵌、自托管的 **ッツ Ebook Reader** 离线阅读书籍。
* 阅读经 **Mokuro** 预处理的漫画，并导出或裁剪当前图片。
* 支持 **WebSocket**，便于配合 texthooker 用于视觉小说、游戏等场景。
* 从音乐应用中获取歌词，并对当前播放歌曲的歌词进行词典查询。
* 可用目标语言与 **ChatGPT** 交互，获取语法信息、例句等内容。
* 支持带音高和频率信息的 **Yomichan 词典**，并可按默认状态折叠或展开词典。
* 提供低摩擦的句子挖掘和制卡工作流，支持模块化增强项和自动化。

# 项目现状

**jidoujisho 正在积极寻找贡献者。** 如果你愿意维护词典格式、媒体来源、增强项、快捷动作，甚至为应用添加新语言，用户和开发者文档正在逐步完善中。

这个项目最初为日语学习社区构建，是自由开源软件，并可在 <b><a href="https://github.com/arianneorpilla/jidoujisho/releases">GitHub Releases</a></b> 下载。

请注意，应用的开发节奏会在“实现新变更”和“暂时保持日常使用稳定”之间切换。更新频率取决于问题严重程度。**暂停期也能提供实际使用反馈，帮助判断后续开发方向。**

# 使用应用

### 支持格式

- jidoujisho 可播放 **VLC 支持的视频和音频格式**。建议使用 SDR 视频而不是 HDR。字幕可以内嵌在视频中，并可在播放时选择。
- 如果设备存储空间紧张，可以将本应用作为 [**Jellyfin**](https://jellyfin.org/) 的外部播放器，从电脑媒体库串流播放，并支持进度追踪和外部字幕。
- 外部字幕支持 **SRT、ASS、SSA**，可在播放期间通过菜单导入。你也可以切换不同音轨和字幕轨。当前不支持 PGS 等图像字幕。
- 观看 YouTube 视频时可使用 **隐藏字幕** 和 **自动生成字幕**。这里有一些展示实际用例的视频示例：<b><a href="https://www.youtube.com/watch?v=mZ0sJQC8qkE">示例一</a> <a href="https://www.youtube.com/watch?v=X9zw0QF12Kc">示例二</a> <a href="https://www.youtube.com/watch?v=t1yXDcuwzpY">示例三</a></b>。**如果你无法可靠判断自动字幕是否正确，强烈建议不要依赖自动字幕。**
- **ッツ Ebook Reader** 支持阅读 **EPUB** 或 **HTMLZ**。
- **Mokuro** 书卷必须是 HTML 格式，并且图片位于相对目录中。
- 使用前请确保 Android WebView 已更新，这能解决 ッツ Ebook Reader 或 Mokuro 的常见问题。
- 用户可导入日语 <b><a href="https://foosoft.net/projects/yomichan/">Yomichan</a></b> 词典，<b><a href="https://drive.google.com/drive/folders/1tTdLppnqMfVC5otPlX_cs4ixlIgjv_lH">这里可找到部分词典</a></b>。注意，目前不支持使用 `structured-content` 的 Yomichan 词典。
- 其他支持格式包括 <b><a href="https://legacy.migaku.io/tools-guides/migaku-dictionary/manual/">Migaku</a></b> 和 <b><a href="http://lingvo.helpmax.net/en/troubleshooting/dsl-compiler/dsl-dictionary-structure/">DSL</a></b> 词典。

### 快速开始

应用的基础使用流程如下。

* <a href="https://github.com/arianneorpilla/jidoujisho/releases/">下载并安装最新版本</a> 到 Android 设备。
* 在 *Player* 中从 **本地媒体库** 选择视频，或选择 **YouTube 视频**。
* 在 *Reader* 中打开小说，启动 ッツ Ebook Reader 阅读 **EPUB** 或 **HTMLZ** 文件。
* 使用 **Mokuro** 媒体来源阅读经预处理的 HTML 漫画。
* **点按词语** 即可快速查词，并打开 **Card Creator** 或使用 **Instant Export**。
* 可通过 **横向滑动、音量键或点按当前选择** 关闭词典弹窗。
* 在播放器中 **纵向滑动可打开转写**，并选择时间点或阅读字幕。
* 在播放器中 **横向滑动可重复当前字幕音频**。

### 导出到 AnkiDroid

* 可将当前上下文导出为 **AnkiDroid 卡片**，包含当前图片和音频。
* **如果 AnkiDroid 未在后台运行**，应用会提示你安装或启动它。
* **上次导出的 AnkiDroid 牌组会被记住**，下次导出时继续使用。
* 导出到 AnkiDroid 前，**可以编辑卡片字段**。
* 可创建自己的导出配置来自定义 Anki 导出。

### 使用技巧

* 找不到日语字幕？可以试试 <b><a href="https://kitsunekko.net">kitsunekko</a></b> 或 <b><a href="https://github.com/orgs/Nekomoekissaten-SUB/projects/1">Nekomoekisatten</a></b>。
* 试用不同的 **增强项和快捷动作** 来定制工作流。
* 准备转向单语学习？可以默认折叠双语词典，并把导出字段拆分为展开释义和折叠释义。
* 可使用 [**Jellyfin**](https://jellyfin.org/) 从电脑串流媒体，并支持进度追踪和外部字幕。
* 阅读释义时 **双击一个字符**，可快速选中为词并递归搜索。
* 与选中视频文件同名的 **外部字幕** 会默认加载。
* 如果句子太难，可从 Massif、Tatoeba 或 ImmersionKit 获取 **例句**。
* 如果字幕不同步，可以 **设置延迟**，或在导出音频时 **加入前后余量**。
* 在转写中长按非当前字幕，可以 **导出一段连续多条字幕**。
* YouTube 视频会默认选择最接近 **上次选择画质** 的画质。
* 如果视频带有烧录字幕，可在播放器选项中使用模糊组件遮住字幕。
* 阅读漫画时，可以在导出卡片前裁剪图片。
* 听有声书时，可打开转写并点右上角图标，在播放时阅读字幕。
* 开启 **后台播放** 后，可在后台收听，并在媒体通知中显示实时字幕预览和控制按钮。
* 可点击词典条目最右侧标签上的按钮，将导出限制为单一词典。
* 在 Card Creator 中点按字段图标可 **锁定字段**，适合用同一句子导出多张卡片。
* 用户可以用 ChatGPT 支持的多种语言聊天。**如果你无法准确判断 AI 语言模型输出的正确性，请不要过度依赖它。**
