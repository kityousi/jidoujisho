# 指尖上的连续沉浸式学习

**jidoujisho** 是一个 Android 视频播放器、阅读辅助、图像挖掘工作流和制卡工具包，包含许多对语言学习者特别有用的功能。

- [x] 选择字幕文本后，可在应用内快速查词。
- [x] 可导出卡片到 AnkiDroid，并附带当前上下文截图和音频。
- [x] 选择一个词后，可将句子、答案、释义和读音导出到 AnkiDroid。
- [x] 字幕形态分析支持点按选择和拖动选择。
- [x] 横向轻扫即可从头重复当前字幕。
- [x] 纵向滑动可打开转写，用于跳转时间点和复习字幕。
- [x] 支持播放带日语隐藏字幕的 YouTube 视频。
- [x] 可使用制卡器模式，配合导入的照片和文本快速搜索图片和释义。
- [x] 词典标签会记住所查词语，便于跨会话复习，并能回到原上下文。
- [x] 可导入 Yomichan 压缩词典，并从 Kanjium 导出带音高重音信息的卡片。
- [x] 通过 ッツ Ebook Reader 为小说阅读提供顺畅的句子挖掘工作流。
- [x] 可用基于 Google ML Kit OCR 的图像挖掘工作流挖掘漫画。
- [x] 可用内置浏览器在手机上阅读和挖掘网页词语，也可以使用相机。

# 使用应用

### 支持格式

jidoujisho 可播放 **VLC 支持的视频和音频格式**。字幕可以内嵌在视频中，并可在播放时选择。

外部字幕支持 **SRT、ASS、SSA**，可在播放期间通过菜单导入。你可以切换不同音轨和字幕轨。当前不支持 PGS 等图像字幕。

**YouTube 隐藏字幕** 来自 TimedText XML，只有公开视频中由用户生成的日语字幕会暴露出来。这里有一些展示实际用例的视频示例：<b><a href="https://www.youtube.com/watch?v=mZ0sJQC8qkE">示例一</a> <a href="https://www.youtube.com/watch?v=X9zw0QF12Kc">示例二</a> <a href="https://www.youtube.com/watch?v=t1yXDcuwzpY">示例三</a></b>。

漫画或漫画书可通过选择包含章节子文件夹和图片的文件夹来查看。

### 快速开始

* <a href="https://github.com/arianneorpilla/jidoujisho/releases/">下载并安装最新版 beta</a> 到 Android 设备。
* 在 *Player* 中从本地媒体库选择视频，或选择 YouTube 视频。
* 在 *Reader* 中启动 ッツ Ebook Reader 阅读 EPUB 或 HTMLZ。
* 在 *Viewer* 中选择包含章节子文件夹和图片的文件夹来阅读漫画。
* 使用点按选择或拖动选择文本。
* 当文本的词典释义出现时，该文本就是当前上下文。
* 关闭词典提示会清空剪贴板。
* 长按词头或在弹出词典中纵向滑动，可切换词典。
* 在播放器中纵向滑动可打开转写并跳转时间点。
* 在播放器中横向滑动可重复当前字幕音频。
* 在词典结果上左右滑动，可浏览多个释义。
* 在 *Viewer* 中可使用 OCR 从图片获取文本。

### 导出到 AnkiDroid

* 可将当前上下文导出为 AnkiDroid 卡片，包含当前画面和音频。
* 剪贴板中有词语时，导出会包含句子、词语、释义和读音。
* 导出前可以编辑句子、词语、释义和读音字段。
* 卡片正面只包含句子。
* 卡片背面包含音频、图片、读音、词语和释义。
* 导出后可在 AnkiDroid 编辑器中继续设置文本格式。
* 可通过修改 AnkiDroid 中的默认模板来自定义导出。

### 高级技巧

* 找不到日语字幕？可以试试 <b><a href="https://kitsunekko.net">kitsunekko</a></b>。
* 可导入自己的 <b><a href="https://foosoft.net/projects/yomichan/">Yomichan</a></b> 自定义词典用于离线即时查询。
* 在弹出词典中长按词头或纵向滑动，可快速切换词典。
* 与选中视频同名的外部字幕会默认加载。
* 如果字幕不同步，可以设置延迟，或为导出音频加入余量。
* 主菜单顶部有继续按钮，可回到上次视频或书籍。
* 可从词典结果中选择 *Context* 回到视频精确时间或书籍滚动位置。
* 在 *List new channel* 中粘贴频道任意视频链接，也可添加频道。
* 也可观看 Plex 服务器视频或直接网络流。
* 在转写中长按非当前字幕，可导出一段连续多条字幕。
* 如果 AnkiDroid 未在后台运行，请点按导出消息打开它。
* 上次导出的 AnkiDroid 牌组会被记住。
* YouTube 默认选择最接近上次选择的画质。
* 阅读漫画时，可在 *Creator* 中裁剪漫画分格，让卡片上下文更清晰。

# 贡献与署名

jidoujisho 使用 <b><a href="https://dart.dev/">Dart</a></b> 编写，由 <b><a href="https://flutter.dev/">Flutter</a></b> 驱动。阅读器 WebView 连接到 <b><a href="https://ttu-ebook.web.app">ッツ Ebook Reader</a></b>。视频串流使用 <b><a href="https://youtube.com/">YouTube</a></b>。图片搜索使用 <b><a href="https://bing.com//">Bing</a></b>。音频搜索使用 <b><a href="https://forvo.com//">Forvo</a></b>。例句来自 <b><a href="https://massif.la">Massif</a></b> 和 <b><a href="https://tatoeba.org/">Tatoeba</a></b>。

自然语言处理工具包括通过 <b><a href="https://chaquo.com/chaquopy/">Chaquopy</a></b> 为中文使用的 <b><a href="https://github.com/fxsjy/jieba">jieba</a></b>，用于日语的 <b><a href="https://github.com/Kimtaro/ve">Ve</a></b> 和 <b><a href="https://pub.dev/packages/mecab_dart">MeCab</a></b>，以及用于韩语的 <a href="https://github.com/shirakaba/mecab-ko"><b>MeCab</b></a>。日语音高重音模式来自 <b><a href="https://github.com/mifunetoshiro/kanjium">Kanjium</a></b>。OCR 由 <b><a href="https://developers.google.com/ml-kit">Google ML Kit</a></b> 提供。

如果你喜欢目前的成果，可以通过在不同设备上测试应用来帮助作者了解 Android 版本兼容性，也可以 <b><a href="https://www.ko-fi.com/arianneorpilla">捐赠</a></b> 或参与后续改进。

应用 Logo 由 <b><a href="https://88suzysuzy.carrd.co/">suzy</a></b> 和 <b><a href="https://www.buymeacoffee.com/marblesaa">Aaron Marbella</a></b> 共同创作，如果可以，请支持他们的优秀作品。
